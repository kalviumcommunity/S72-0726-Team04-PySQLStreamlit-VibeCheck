## Conventions

- Branch: `<name>/day-NN-short-slug`, one PR per roadmap day.
- File: `docs/prs/<name>/day-NN-short-slug.md`, using the sections *Summary · Why · What changed · How to test ·
  Result · Diff highlight · Checklist*.
- Add your row to `<name>/README.md` in the same PR.
